# API Surfaces and Authentication

> **Created:** 2025-08-06
> **Updated:** 2026-09-25

Supervaizer exposes FastAPI's generated documentation plus four route surfaces with different access rules.

## Route Surfaces

| Surface | Access rule |
| --- | --- |
| `/`, `/.well-known/*`, `/docs`, `/redoc`, `/openapi.json` | Public, no authentication |
| `/api/*` (for example `/api/supervaizer/...`, `/api/agents/{slug}/...`) | `X-API-Key` header required; 401 when missing or wrong. Mounted only when Studio credentials are configured or local mode is on |
| `POST /a2a`, `GET /a2a/events` | `X-API-Key` with `write` scope for `/a2a`, `read` scope for `/a2a/events`; 403 when the scope is insufficient |
| `/manage/*` (admin UI and workbench) | Tailscale client IP only, no API key. See [2025_08_ADMIN_README.md](2025_08_ADMIN_README.md) |

## API Key

- `SUPERVAIZER_API_KEY` registers a `write`-scope key at import time. `write` implies `read`.
- Outside local mode, if the variable is unset a key is generated at startup and only its fingerprint is logged. Set `SUPERVAIZER_API_KEY` explicitly if you need to call `/api` or `/a2a` yourself.
- Local mode (`supervaizer start --local`) uses the key `local-dev`.
- Denied requests are logged at `WARNING` with IP, path, reason, and a truncated key preview, never the raw key.

## Interactive Documentation

| Interface | URL | Notes |
| --- | --- | --- |
| Swagger UI | `http://localhost:8000/docs` | Try requests in the browser |
| ReDoc | `http://localhost:8000/redoc` | Read-only reference |
| OpenAPI schema | `http://localhost:8000/openapi.json` | OpenAPI 3.1, machine readable |

The schema declares no security scheme, so Swagger shows no **Authorize** button. To call a protected route from Swagger, open the operation, click **Try it out**, and fill the `X-API-Key` header field.

## Committed OpenAPI Spec

`docs/api/openapi.json` is generated by `just generate-docs` from `src/supervaizer/examples/controller_template`. Agent-specific routes in it belong to that example; your controller's spec lives at `/openapi.json` on the running server.
